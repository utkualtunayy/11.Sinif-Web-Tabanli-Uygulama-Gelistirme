# 🌐 Web Tabanlı Uygulama Geliştirme Projeleri

11. sınıfta Web Tabanlı Uygulama Geliştirme dersi kapsamında geliştirdiğim HTML, CSS ve JavaScript projelerinin bulunduğu depodur.

## 📌 Hakkında
Bu repository içerisinde ders boyunca geliştirdiğim çeşitli web projeleri yer almaktadır. Projeler; web tasarımını, kullanıcı arayüzü geliştirmeyi ve JavaScript ile etkileşimli web sayfaları oluşturmayı öğrenmek amacıyla hazırlanmıştır.
